v0.6.0

Knowledge specialists in the multi-agent planner, attachments that stay in context, a rebuilt PDF renderer, one rule for when tools are on, and tool approvals that survive a restart — with desktop installers for macOS, Windows, and Linux.

### Highlights

- **Knowledge specialists (multi-agent Phase 2).** The planner routes steps to `research`, `fact_check`, `summarize`, and `document` specialists, each with its own prompt and tool allowlist. A fact-check step is soft-inserted after research, and dependent steps receive prior step outputs instead of starting cold.
- **Per-specialist model picks.** Settings assigns a model per step kind; anything unset falls back to the tool-executor model, then the chat model.
- **Attachments stay in the conversation.** Images and documents are persisted as messages and re-injected on later turns, so a follow-up question can still see a file you sent earlier.
- **Much better PDFs.** A dedicated print stylesheet, real Markdown table rendering, and a rewritten HTML pipeline replace the previous ad-hoc output.
- **Document turns that finish the job.** After two research-only tool rounds on a turn that clearly wants a document, the model is nudged once to call `generate_document`.
- **One rule for "tools enabled".** `resolveUseTools` is the single source of truth: tools default to ON, and only an explicit `false` turns them off, so the toggle, the project default, and the request path cannot disagree.
- **Customize is a three-step wizard.** Personal context is collected in stages rather than one long form.
- **Interface refresh.** Composer toolbar controls share one height, the sidebar reserves a gutter for activity dots, workspace buttons meet contrast in dark theme, and the stylesheet was reworked throughout.
- **Branded OAuth return pages.** The loopback server renders success and failure pages that look like the app.
- **Unanswered tool approvals are no longer lost.** A risky-tool confirmation is stored on disk and offered again next time you open that conversation — after a timeout, a stopped turn, or an app quit. Approving replays the saved call on its own, and the in-session wait grew from 2 to 10 minutes.

### Fixes

- Splash no longer hangs when a sandboxed preload crashes on launch.
- Notification clicks reliably raise the window (focus logic moved into the window module).
- Router no longer reads a bare "look up" as research, or a bare "document" as retrieval.
- Async conversation patches land on the conversation they started in, even if you navigate away mid-flight.
- Web: Open Graph image host repaired and meta copy shortened.

### What's new and internals

- `agents/`: Phase 2 step kinds parsed, planned, routed, and run; `modelForStepKind` resolves per-kind models with fallbacks.
- `documents/`: new `pdf-css.ts`, `md-html.ts`, `md-table.ts`, `auto-tools.ts`, plus `doc-nudge` state threaded through the chat loop.
- `use-tools.ts`: `DEFAULT_USE_TOOLS` + `resolveUseTools` consumed by the store, project defaults, and the renderer toggle.
- `pending-confirms.ts` / `pending-confirms-data.ts` / `confirm-resume.ts`: persisted confirmations with pure, unit-tested rules and a standalone replay path.
- `oauth/pages.ts`: inline-styled one-shot callback pages.
- Renderer: `conversation-target.ts`, `web-research-hint.ts`, `customize-steps.ts`, `restored-confirms.ts`.
- Landing page: reworked Hero and Constellation layering, globals refresh, Firebase host page updated.

### Upgrade notes

- No migration required. Existing chats, projects, and settings are read as-is.
- Conversations with no stored `useTools` value now resolve to ON. If you relied on the old ambiguous default, check the per-chat toggle after upgrading.
- Per-specialist model settings start empty and fall back to your chat model, so multi-agent behaviour is unchanged until you set them.
- Existing installs that use electron-updater will pick up `latest*.yml` from this release when auto-update is enabled.
- Builds are unsigned unless Apple/Windows code-signing secrets are configured; macOS may need a one-time **System Settings → Privacy & Security → Open Anyway** approval on first launch.
