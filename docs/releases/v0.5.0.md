v0.5.0

Tools control that sticks, stronger document generation, privacy-first analytics, and a sharper download site — with desktop installers for macOS, Windows, and Linux.

### Highlights

- **Tools toggle + defaults.** Labeled Tools control in the composer, with project-wide persistence and a choice for new general chats.
- **Model lock clarity.** After the first message, the model picker looks disabled and explains why on hover.
- **Research-then-write documents.** Document turns prefer search → fetch → generate, with a thin-content guard so stub PDFs/DOCX/MD do not get written.
- **Privacy & analytics.** Soft-ask consent on boot, Privacy settings tab, and opt-in field groups for product/reliability events (PostHog in the desktop app).
- **Site polish.** Clearer download UX, product-accurate catalogs, SEO/metadata, privacy page, and brand assets.
- **Release pipeline.** Split Release/Build workflows that attach macOS, Windows, and Linux installers directly to GitHub Releases.

### What's new and internals

- `defaultUseTools` settings + project bulk thread patch; tools scope modal for general chats; hardened toggle updates bound to the originating chat.
- Document intent/prompt guidance, `content-quality` assess helper before write, and PDF CSS polish.
- Main-process analytics client with policy filter, IPC capture surface, consent modal, and Privacy settings UI.
- Marketing site SEO helpers, analytics, release notes markdown rendering, and download/catalog fixes.
- CI: tag-driven release notes from `docs/releases/`, matrix builds, and merged `latest*.yml` auto-update feeds.

### Upgrade notes

- Existing installs that use electron-updater will pick up `latest*.yml` from this release when auto-update is enabled.
- Builds are unsigned unless Apple/Windows code-signing secrets are configured; macOS may need a one-time **System Settings → Privacy & Security → Open Anyway** approval on first launch.
- Analytics is soft-ask: capture uses defaults until you Accept, Decline, or change Privacy settings. No full message bodies, tool payloads, or absolute paths are sent.
