## Description (Product Hunt “description”)

AnyLM is a local-first desktop app for people who already run models with Ollama.

Create projects, attach reference docs for retrieval-augmented chat, run multi-agent turns, and expose one OpenAI-compatible endpoint so Cursor, Continue, and your scripts share the same local runtime — without shipping prompts to the cloud.

Installers for macOS, Windows, and Linux. Open source (MIT).

## First comment (maker)

Hey Product Hunt 👋

I’m Yash — I built **AnyLM** because I wanted Claude Projects–style context on top of the models already living on my machine via Ollama, plus a single local API every editor and script could hit.

**What’s in v0.4**

- Projects with instructions + RAG over attached docs  
- Streaming chat, reasoning stream, and multi-agent orchestration  
- Local OpenAI-compatible proxy so other apps share one resident runtime  
- Artifacts explorer, Ollama setup gate, load protection  
- macOS / Windows / Linux installers from GitHub Releases  

**How to try it**

1. Install [Ollama](https://ollama.com) and pull a chat model (+ `nomic-embed-text` for RAG)  
2. Download AnyLM from [anylm.app/download](https://anylm.app/download)  
3. Sign in, create a project, attach a doc, chat  

Would love feedback from local-LLM folks — especially if you live in Cursor/Continue and want one endpoint instead of N copies of the same weights. AMA!
